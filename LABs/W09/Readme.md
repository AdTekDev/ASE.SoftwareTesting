# W09. Test Plan

## **Part 1: Estimating: Testing an Online Ordering System (Fahasa)**

[Individual Assignment]
Students are required to perform testing activities related to the **book ordering process on the Fahasa website**.

### **Requirements**

1. **Write Detailed Test Scenarios**

   * Describe step-by-step scenarios for ordering books on Fahasa.
   * Include both normal flows and alternative/exception flows (e.g., out-of-stock, invalid input, payment failure).

2. **Design Comprehensive Test Cases**

   * Create a complete set of test cases covering:

     * Functional scenarios (search, add to cart, checkout, payment, etc.)
     * Boundary cases
     * Negative cases (invalid data, system errors)
   * Use a standard test case format (ID, description, preconditions, steps, expected result, etc.).

3. **Develop Test Scripts (Automation or Manual Simulation)**

   * Create **at least 3 test scripts** for selected scenarios.
   * Scripts can be written using tools such as Selenium or described in structured pseudo-code if automation is not implemented.

4. **Time Tracking**

   * Record the time spent on each activity:

     * Test scenario design time
     * Test case design time
     * Test script development time
     * Test execution time
     * Test reporting time

## **Part 2: Test Plan Based on IEEE 829**

Students will work in groups to create a **basic Test Plan** following the **IEEE 829 standard** for a selected software project.

### **Requirements**

Develop a structured test plan including the following sections:

1. **Test Plan Identifier**
2. **Introduction**

   * Objectives
   * Scope of testing
3. **Test Items**
4. **Features to be Tested / Not Tested**
5. **Test Approach**

   * Testing types (functional, regression, etc.)
   * Tools and techniques used
6. **Item Pass/Fail Criteria**
7. **Suspension and Resumption Criteria**
8. **Test Deliverables**
9. **Testing Tasks**
10. **Environmental Needs**
11. **Responsibilities**
12. **Schedule**
13. **Risks and Contingencies**
14. **Approvals**
