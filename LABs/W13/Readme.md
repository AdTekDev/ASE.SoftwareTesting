# W13. Bug Report

---

🐞 BUG (DEFECT) CLASSIFICATION   

## 1. By Severity (Impact Level)

Describes how serious the defect is:

* **Critical** – System crash, data loss, security breach
* **High** – Major functionality broken, no easy workaround
* **Medium** – Partial functionality affected
* **Low** – Minor issue (UI, typo, cosmetic)

---

## 2. By Priority (Fix Urgency)

Describes how quickly the defect should be fixed:

* **P1 (High Priority)** – Fix immediately
* **P2 (Medium Priority)** – Fix soon
* **P3 (Low Priority)** – Fix later

📌 Note: Severity ≠ Priority

---

## 3. By Defect Type

### Functional Defect

* Business logic does not work as expected

### UI (User Interface) Defect

* Layout, alignment, colors, fonts issues

### Usability Defect

* Poor user experience, confusing flow

### Performance Defect

* Slow response, high latency, system lag

### Security Defect

* Vulnerabilities (e.g., SQL Injection, XSS)

### Compatibility Defect

* Works differently across browsers/devices/OS

### Integration Defect

* Issues between modules or services

### Data Defect

* Incorrect data handling or storage

---

## 4. By Root Cause (Origin)

* **Requirement Defect** – Missing/incorrect requirements
* **Design Defect** – Poor architecture or design flaw
* **Coding Defect** – Implementation error
* **Configuration Defect** – Environment/setup issue
* **Documentation Defect** – Incorrect or missing docs

---

## 5. By Environment

* **Development (Dev)**
* **Testing / QA / Staging**
* **Production (Live)**

---

## 6. By Reproducibility

* **Always Reproducible**
* **Intermittent (Sometimes)**
* **Rare**
* **Not Reproducible (Cannot Reproduce)**

---

## 7. By Status (Lifecycle)

* New
* Assigned
* Open
* In Progress
* Fixed
* Retest
* Verified
* Closed
* Reopened
* Deferred
* Rejected

---

## 8. By Detection Phase

* Requirement Phase
* Design Phase
* Development Phase
* Testing Phase
* Production Phase

---

## 9. By Test Level

* Unit Level Defect
* Integration Level Defect
* System Level Defect
* Acceptance Level Defect

---

## 10. By Frequency / Occurrence

* **Permanent** – Always happens
* **Intermittent** – Occurs occasionally
* **One-time** – Happens once

---

## 11. By Risk / Business Impact

* **Business Critical** – Affects revenue or core operations
* **Major** – Affects important features
* **Minor** – Limited impact
